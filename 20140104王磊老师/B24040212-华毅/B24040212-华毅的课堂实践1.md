## 五、基础 Shell 命令操作

### 1. 查看当前工作目录

执行命令：

```bash
pwd
```

输出结果：

```text
/home/vip
```

说明：当前位于用户 `vip` 的主目录中。

### 2. 查看主目录内容

执行命令：

```bash
ls
```

结果显示了用户主目录中的多个文件夹，包括“下载”“公共”“图片”“文档”“桌面”“模板”“视频”和“音乐”等。

### 3. 创建并进入 `njupt` 目录

依次执行命令：

```bash
mkdir njupt
cd njupt
```

执行后，命令提示符中的路径由 `~` 变为 `~/njupt`，说明目录创建成功并已进入该目录。

### 4. 创建并查看 `hello.txt` 文件

依次执行命令：

```bash
touch hello.txt
ls
```

输出结果：

```text
hello.txt
```

说明：`hello.txt` 文件已创建成功。

### 5. 写入并读取文件内容

依次执行命令：

```bash
echo "I love njupt" > hello.txt
cat hello.txt
```

输出结果：

```text
I love njupt
```

说明：字符串已成功写入 `hello.txt`，并通过 `cat` 命令正确读取。
