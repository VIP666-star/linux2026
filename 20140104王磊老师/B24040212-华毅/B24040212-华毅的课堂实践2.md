## 三、nginx 服务的安装

执行命令：

```bash
sudo apt install nginx -y
```

说明：一条命令即可完成安装。Ubuntu 在安装 nginx 时会自动启动服务，并设置开机自启。

检查服务运行状态：

```bash
systemctl status nginx
```

输出结果（摘要）：

```text
Active: active (running)
├─8501 "nginx: worker process"
└─8502 "nginx: worker process"
```

说明：nginx 服务已处于运行状态（`active (running)`），并已启动 worker 工作进程。

## 四、查询虚拟机 IP 地址

依次执行命令：

```bash
ifconfig
# 若提示找不到命令，可先安装 net-tools，或改用新命令
sudo apt install -y net-tools
ip addr
```

输出结果（摘要）：

```text
inet 192.168.140.128/24
```

说明：查得本虚拟机的 IP 地址为 **192.168.140.128**，该地址将用于从 Windows 宿主机远程访问。

## 五、在 Windows 浏览器中远程访问（默认页面）

在 **Windows** 浏览器地址栏中输入（必须使用 http）：

```text
http://192.168.140.128
```

输出结果：成功显示 nginx 默认欢迎页面 **Welcome to nginx!**

说明：这一步同时验证了三件事——nginx 服务正常、虚拟机与宿主机网络互通、防火墙未拦截 80 端口。这也是从宿主机"远程访问"虚拟机上服务的成功标志。

## 六、添加自定义首页 index.html

切换到 root 用户（网站根目录 `/var/www/html` 属于 root，普通用户无写入权限）：

```bash
sudo su root
```

进入网站根目录并查看内容：

```bash
cd /var/www/html
ls -l
```

输出结果（摘要）：

```text
index.nginx-debian.html
```

备份默认首页（可选，因 nginx 首页查找顺序中 `index.html` 优先，新建的 `index.html` 会自动生效）：

```bash
mv index.nginx-debian.html index.nginx-debian.html.bak
```

写入自定义首页内容：

```bash
echo '<html><body>hello, njupt</body></html>' > /var/www/html/index.html
```

说明：也可以使用 `vi` 编辑器（`apt install vim`）或图形界面编辑，操作方式为
`vi /var/www/html/index.html` → 按 `i` 进入插入模式输入内容 → 按 `Esc` → 输入 `:wq` 保存退出。

检查写入结果：

```bash
cat /var/www/html/index.html
ls -l /var/www/html/index.html
chmod 644 /var/www/html/index.html   # 如权限不正确则修正
exit
```

输出结果（摘要）：

```text
<html><body>hello, njupt</body></html>
-rw-r--r-- 1 root root ... /var/www/html/index.html
```

说明：文件内容正确，属主为 root、权限为 644。静态文件由 nginx 实时读取，**修改后不需要重启 nginx**。

## 九、操作过程中遇到的问题与解决

| 问题现象 | 原因分析 | 解决方法 |
| --- | --- | --- |
| 虚拟机显示 Powered On 但画面全黑、键鼠无响应 | 虚拟机此前被**挂起**，恢复时显示状态未成功恢复（日志提示 `No SVGA screens defined at checkpoint restore`），客户机也未响应 | 在 VMware 中强制关闭客户机后**冷启动**，进入 GRUB 菜单按回车正常引导；此后改用"关闭客户机"，不再使用"挂起" |
| `systemctl status ssh` 显示 `inactive (dead)` | Ubuntu 新版采用 `ssh.socket` **按需启动**，服务平时未激活，但端口 22 实际一直在监听 | 用 `systemctl status ssh.socket`、`ss -tlnp \| grep ':22'` 确认监听状态，无需修改 |
| 向 `/var/www/html` 写入文件提示权限不足 | 该目录属主为 root | 先执行 `sudo su root` 提权，再写入文件 |
| 执行 `curl` 提示"找不到命令" | 系统未预装 curl 工具 | 执行 `sudo apt install -y curl` 安装 |
